## I. Jak číst Foundation Library

**Document ID se po vydání nemění** (stabilní odkazy, git historie, Time Capsule).

**Pořadí čtení** (doporučené pro nového čtenáře) se může lišit od čísel:

1. Founding Statement (srdce)  
2. Manifesto (jedna stránka víry)  
3. Constitution (závazek a pilíře)  
4. The ShadowGuard Way (jak pracujeme)  
5. Decision Protocol (jak rozhodujeme)  
6. Book of Decisions + Chronicle (paměť)  
7. Ostatní podle potřeby

## V. Release policy (stručně)

- **Foundation Library** = kniha manuskriptů.  
- **Founding Edition** = historický milník (oficiální release), ne synomymum pro každou složku.  
- První veřejný release **Founding Edition v1.0** až po interní revizi (včetně konzistence a jazyků) — **ještě ne teď**.  
- Release je slib: „toto je naše oficiální filozofie.“
